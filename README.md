# 学校校務の生成AI 30回講座

生成AIに一度触れたことがある職員が、日々の校務を題材に「自分の仕事でも使える」と分かるようになるための、30回の講座です。気になる回を、ひとつ試すところから始められます。

初心者向けの講座を終えた人が対象です。扱うのは全30回とも、私生活や一般的な作業ではなく、学校の校務そのものです。学級担任を中心に、校務分掌の主担当でなくても自分の担当範囲で実行できる内容にしています。

## 参加のしかた

- 自由参加です。30回すべてをやる必要はありません。
- 順番も速さも自由です。1日に何回やっても、間があいてもかまいません。
- ランキング、提出、成績評価はありません。取り組んだ数を競う企画でもありません。
- 生成AIを開けないときは、文章を読んで「どんな返事が来そうか」を考えるだけでも参加できます。

## 大切にしていること

生成AIの回答は「正解」や「完成品」ではなく、考えるための材料です。返事を読んだら、自分の考え、学校の実情、条件、違和感をもう一言だけ返してください。採用するか、直すか、使わないかを決めるのは利用者自身です。

**AIの回答をそのまま校務に使わないでください。** 事実に関わる内容は、元の文書、通知、要領、公的機関の情報で必ず確かめます。学校ごとの決まりや事情に合わせて書き直したうえで使います。この点を確かめる手順そのものを、複数の回で本題として扱っています。

## 1つの回の進み方

回をひらくと、次の順で並んでいます。**手順の番号は1回目から2回目まで通しで振ってあります。**

1. **1回目に送る** — 生成AIに送る文章と、そこまでの手順
2. **返事が来ます** — 何を見ればよいかを1行で書いています。ここがその回のねらいです
3. **2回目に送る** — 空欄を自分の言葉でうめて、新しいメッセージとして送ります

添付や貼り付けが必要な回は、**添付と文章が同じメッセージで、送信は1回**であることを手順に明記しています。

## 扱う校務の種類

| 種類 | 回数 | 例 |
|---|---|---|
| 文書をつくる・直す | 7 | 起案の趣旨、行事の要項、依頼文、掲示、報告書 |
| 数字と表を扱う | 6 | 表計算の式、自由記述の分類、表記ゆれ、集計の読み取り |
| 会議・打ち合わせ | 6 | 提案の抜け、レジュメ、議事録、想定される反対意見 |
| 保護者・外部への連絡 | 5 | 専門用語の言い換え、問い合わせへの返事、想定質問 |
| 点検・引き継ぎ | 6 | 根拠の確認、提出前の点検、手順書、一年の見通し |

## 操作の種類と色

「そのままコピーすればよいのか、自分で何か足すのか」が分かるように、操作の種類ごとに色とラベルを分けています。

| 色 | ラベル | 利用者がすること |
|---|---|---|
| 青 | そのままコピーして送る | コピーして貼り付けるだけ |
| 緑 | 自分の文を貼ってから送る | 自分で書いた文章を貼り付けてから送る |
| 紫 | 写真・資料を添付してから送る | 写真や資料を添付してから送る |
| 黄 | 空欄をうめてから送る | 文の空欄を自分の言葉でうめてから送る |
| 赤 | 注意 | この色は注意以外で使いません |

色は2番目の手がかりです。**ラベルとアイコンだけで何をするか決まる**ようにしてあるので、色の見分けが難しい人でも困りません。

## くわしく

実際に詰まる4か所にだけ、補足を用意しています。回ごとに書き分けず、共通の4本を参照しています。

- 添付ボタンの場所
- 1回で送る
- 新しいメッセージ
- 貼り付け

補足は**押しても、マウスを乗せても開きます**。マウスのない携帯やタブレットでも読めるようにするためです。

## 記録

「やってみた」の印だけを、利用中の端末に保存します。件数や達成率、ごほうびの仕組みはありません。

## プライバシーとデータ

- 児童・保護者・職員の氏名、顔、連絡先、学習の記録、健康に関する情報などの個人情報や、学校の機密情報を入力・撮影・添付しないでください。
- 添付が必要な回では、**個人が分かる情報を取り除く手順を、添付する前の手順として示しています。**
- 練習には、公開済みの資料、個人を特定できない文書、同梱の練習用素材を使ってください。
- 空欄をうめる入力欄がありますが、書いた言葉はこのサイトの外へ送らず、端末にも保存しません。画面を閉じると消えます。
- 「やってみた」の印だけを `localStorage` に保存します。入力内容や生成AIの回答は収集しません。
- 外部API、アクセス解析、広告、トラッカーは使用しません。生成AIサービスとの通信もこのサイトからは行いません。

### 練習用の素材

添付や貼り付けが必要な回では、探す手間で止まらないよう練習用の素材を同梱しています。すべて架空の内容で、実在の学校・自治体・団体・人物とは関係ありません。氏名にあたる部分は役割名に置き換えてあります。**サイトのトップページからも開けます。**

- `assets/sample-notice.md`：架空の教育委員会通知（校外学習とバス借上げ）
- `assets/sample-minutes.md`：架空の学年打ち合わせメモ（走り書きのまま）
- `assets/sample-survey.md`：架空のアンケート集計（4段階評価と自由記述）
- `assets/sample-check-doc.md`：架空の点検用文書（日付・合計・表記・宛先・項目に誤りを混ぜてあります）
- `assets/sample-error-screen.svg`：架空の機器エラー画面（自前のSVG。外部を読み込みません）

実際の校内文書には、個人情報のほかに、まだ公表していない日程・予算・分担などの機密情報が残ることがあります。練習にはこれらの架空素材を使ってください。

## 使い方

### GitHub Pages

公開後はURLをブラウザで開くだけで使えます。携帯にも対応しています。

### ローカルで見る

このリポジトリを取得し、プロジェクト直下で静的ファイルを配信します。

```powershell
python -m http.server 4173
```

その後、`http://localhost:4173/` をブラウザで開きます。ビルドツールやAPIキーは不要です。

## 開発・確認

Node.js 22以降を想定しています。

```powershell
npm test
npm run build:print
npm run test:smoke
```

- `npm test`: 内容、記録、画面構造、印刷用ページ、公開文書のテスト
- `npm run build:print`: `js/challenges.js` から印刷用の `print.html` を再生成
- `npm run test:smoke`: ブラウザで主要操作を確認

## 内容を更新する

本文の正本は [`js/challenges.js`](./js/challenges.js) です。更新後は `npm run build:print` を実行し、画面と印刷用ページの内容をそろえてから `npm test` を実行してください。生成済みの `print.html` を直接編集しないでください。

改善提案や誤りの報告は、公開リポジトリのIssueまたはPull Requestで歓迎します。実在する児童・保護者・職員や学校内部の情報は、Issue、Pull Request、サンプルデータ、画像のいずれにも含めないでください。
